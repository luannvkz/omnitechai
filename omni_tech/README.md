Omni Tech - Chatbot com Tkinter + Groq (openai/gpt-oss-120b)

1. Python 3 com Tkinter (nenhuma biblioteca extra necessária).
2. Defina a chave da Groq (https://console.groq.com):
   Windows (cmd):  set GROQ_API_KEY=sua_chave
   Linux/Mac:      export GROQ_API_KEY=sua_chave
3. Execute:  python main.py
Login: admin / 1234 (altere em config.py)
